📖 Термины и объяснения

📊 Категории чартов
	•	Top-grossing — топ приложений по выручке (от покупок внутри приложений, подписок и платных загрузок).
	•	Top-free — топ бесплатных приложений по количеству загрузок.
	•	Top-paid — топ платных приложений (те, которые покупают сразу при установке).

⸻

💰 Метрики денег
	•	ARPU (Average Revenue Per User) — средняя выручка на пользователя. Если в стране 1 млн пользователей и они суммарно платят $10 млн → ARPU = $10.
	•	Top-grossing плотность — «насыщенность» категории или страны в чартах топ-grossing. Например, в топ-100 grossing 50% приложений = игры → высокая плотность игр.
	•	IAP (In-App Purchases) — покупки внутри приложения (доп. функции, подписки, контент).

⸻

📅 Временной анализ
	•	Когорта — группа объектов, вышедших/созданных в один период.
	•	Когорта релиза = приложения, выпущенные в 2018 году.
	•	Анализируется их траектория: сколько из них попали в топы, через сколько времени, как держались.
	•	Sweet spots — в аналитике: «сладкие точки», ниши, где спрос есть, конкуренция ниже, и есть шанс заработать.

⸻

🌐 Источники данных
	•	RSS-ленты App Store — Apple публикует фиды (списки) приложений в топах (JSON/XML), их можно парсить ежедневно/еженедельно.
	•	Wayback Machine — интернет-архив, сохраняет старые версии сайтов. Можно восстановить чарт/страницу приложения за прошлые годы.

⸻

🌍 Экономические термины
	•	GDP PPP per capita — ВВП по паритету покупательной способности на душу населения. Это способ сравнить, сколько товаров/услуг реально можно купить в стране за средний доход (не искажённый курсами валют).
	•	Карточная пенетрация — доля населения с банковскими картами/электронными платежами. Чем выше, тем легче монетизировать приложения.

⸻

📈 Модели и метрики
	•	Ранг→ревеню-модель (логарифмическая/степенная) — метод оценки выручки по месту в топе. Например: приложение на 1 месте в grossing зарабатывает условно $1 млн/день, на 10 месте — $200k, на 100 месте — $10k. Зависимость нелинейная (логарифм/степенная кривая).
	•	Grossing Rank Area Under Curve (AUC по времени) — интегральная метрика «суммарная площадь под кривой» ранга. Пример: приложение держалось месяц в топ-10 и год в топ-50 → это считается сильной позицией.
	•	Top Grossing Share — доля мест в чарте grossing, занимаемая определённой категорией или страной.
	•	Динамика YoY (Year-over-Year) — изменение метрики год к году (например, рост загрузок на +15% YoY).

⸻

🛠️ Инструменты
	•	App Store RSS — см. выше, фиды Apple.
    •   DAG - Directed Acyclic Graph.
	•	S3-like — облачное хранилище наподобие Amazon S3 (можно хранить сырые JSON/CSV).
	•	polars — библиотека для работы с данными, похожая на pandas, но быстрее и эффективнее (особенно для больших датасетов).
	•	EDA (Exploratory Data Analysis) — исследовательский анализ данных: первичные графики, распределения, корреляции.
	•	Временные ряды:
	•	statsmodels (STL) — библиотека Python, STL = Seasonal-Trend decomposition using Loess (разложение ряда на тренд + сезонность + шум).
	•	prophet / neuralprophet — библиотеки для прогноза временных рядов (разработаны Facebook).

⸻

⚙️ Организация процессов
	•	Оркестрация (prefect / airflow / cron + make) — инструменты, чтобы автоматизировать и планировать пайплайн (сбор данных → очистка → анализ).
	•	Контейнеры (Docker + docker-compose) — способ упаковать код и зависимости в контейнер, чтобы запускалось одинаково на любом сервере.
	•	Дашборд (Streamlit / Plotly Dash) — веб-интерфейс для интерактивного просмотра графиков и аналитики.
